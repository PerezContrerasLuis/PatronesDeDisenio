# 🧠 Guía de Desarrollo de Patrones
Bienvenido a este repositorio, donde encontrarás ejemplos prácticos de **patrones de diseño creacionales, estructurales y de comportamiento**, implementados con código sencillo y en diferentes lenguajes de programación. Cada patrón cuenta con uno o más ejemplos que muestran cómo puede aplicarse en distintos escenarios y entornos.


Para facilitar su comprensión, cada ejemplo incluye las siguientes secciones:

1. ¿Qué es?
2. ¿Cómo funciona?
3. ¿Cuándo utilizarlo?
4. Problema a resolver — Explicación sencilla de la problemática que se busca resolver mediante el patrón.
5. Diagrama UML
6. Configuración del ejemplo (opcional, solo si es necesario instalar o configurar algo)
7. ¿Cómo ejecutarlo?
8. Código fuente

El objetivo es comprender los patrones de diseño mediante ejemplos prácticos y diferentes implementaciones, identificando cómo y cuándo pueden ser útiles en distintos escenarios.

##  Instalación

1. Clona el repositorio en tu entorno local:

    ```bash
    git clone git@github.com:PerezContrerasLuis/PatronesDeDisenio.git
    ```

2. Accede al directorio :

    ```bash
    cd PatronesDeDisenio/Patrones
    ```
